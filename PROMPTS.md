# Готовые промпты для агента

## Запуск (первый промпт, вставить в Claude Code / Cursor)
> Прочитай `AGENTS.md`, `GDD.md`, `CONVENTIONS.md`, `TASKS.md`.
> Начни с Шага 0. Создай структуру проекта Godot 4.4 для игры
> "Помойка Survivors". Используй placeholder-спрайты (генерируй через скрипт).
> После завершения Шага 0 отметь задачи в `TASKS.md` и напиши, что проверять.

## Продолжение работы (каждый следующий запуск)
> Прочитай `AGENTS.md` и `TASKS.md`. Возьми первую задачу со статусом `[ ]`.
> Реализуй её. Не выходи за рамки задачи. Обнови `TASKS.md` и `CHANGELOG.md`.

## Промпт для реализации конкретной фичи
> Реализуй [название фичи из TASKS.md]. Следуй `CONVENTIONS.md`.
> Все числа — в `Balance`. Компонентный подход. Сигналы через `EventBus`.
> После реализации — краткий отчёт: файлы, как проверить, что дальше.

## Промпт для баланса
> Открой `Balance` (autoload). Пересмотри числа для [оружие/враг/перк],
> чтобы [цель: например, "игрок не умирал на первой волне"].
> Обоснуй изменения в `CHANGELOG.md`.

## Промпт для арта
> Сгенерируй placeholder-спрайты для [сущность] согласно `ART_STYLE.md`.
> Используй `Image.create()` + `ImageTexture.create_from_image()`.
> Цвета — только из палитры. Сохрани как .png в `assets/sprites/placeholder/`.

## Промпт для багфикса
> Баг: [описание]. Найди причину, исправь минимальным изменением.
> Не рефакторить соседний код. Добавь запись в `CHANGELOG.md` (fix: ...).
