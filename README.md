# Помойка Survivors

Абсурдный roguelite survivor, нарисованный мышкой в Paint.

**Статус:** MVP в разработке.
**Целевая версия:** Godot 4.7.2.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| Мышь | Прицел (для Лазерной Указки) |
| Esc | Пауза |

Оружие стреляет **автоматически**.

## Стек

- Godot 4.7.2, GDScript, Forward+.
- Pixel-perfect: 320×180 → upscale ×4 до 1280×720.
- Все спрайты — placeholder, генерируются скриптом (`tools/gen_placeholder.gd`).

## Документация

- `AGENTS.md` — инструкции для ИИ-агента (главный файл для Codex).
- `MVP_PLAN.md` — что именно входит в MVP, а что после.
- `GDD.md` — дизайн: враги, оружие, перки, экономика.
- `ART_STYLE.md` — палитра, размеры, screen effects.
- `CONVENTIONS.md` — код-стиль, слои, autoloads.
- `TASKS.md` — roadmap с чек-боксами.
- `IDEAS.md` — что можно добавить после MVP.
- `CHANGELOG.md` — история изменений.

## Разработка

Проект рассчитан на работу с ИИ-агентом (Claude Code / Cursor / Codex).
Порядок работы:

1. Открыть проект в Godot 4.7.2.
2. Агент читает `AGENTS.md`, берёт первую задачу из `TASKS.md`.
3. Реализует, проверяет, отмечает, коммитит.
