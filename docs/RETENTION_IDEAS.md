# Идеи, чтобы хотелось умирать и начинать заново

Приоритет: короткий цикл «умер → понял почему → захотел ещё».

1. **Уровни опасности (Danger 0–5)** — после победы открывается следующий: больше элит, быстрее враги, меньше говна. Награда — уникальные предметы и титулы на экране героя.
2. **Мета-прогресс «Помойка-банк»** — часть говна/убийств копится между забегами и открывает героев, стартовые бонусы, новые предметы в лавке (уже есть разблокировки героев/оружия по счётчикам).
3. **Ежедневный забег** — один сид на всех, свой герой и модификатор дня («Только ближний бой», «Враги прыгают»); таблица результатов по волнам.
4. **Проклятия на выбор перед волной** — рискованный контракт: +50% говна, но враги быстрее / нет лечения. Решение «взять или нет» создаёт истории.
5. **Могильник с эпитафиями** — уже есть кладбище; добавить «чем убили» + «совет бабки» (подсказка по оружию/предмету).
6. **Редкие события на волне** — крыса-мародёр, гуманитарка с ящиком, метеорит из мусора: короткие всплески, разрывающие рутину.
7. **Билд-синергии с названиями** — набор из 3 предметов даёт именную комбинацию (например «Кислотный дворник»), бонус показывается в инвентаре.
8. **Достижения/секреты** — победа без покупок в лавке, без урона на волне, только хламом, и т. д. Каждое даёт косметику героя.
9. **Боссы с фазами и подсказками** — читаемые телеграфы атак, чтобы смерть всегда ощущалась «моей ошибкой».
10. **Режим «Бесконечность»** после 15-й волны — счёт до смерти, лидерборд по Steam.
